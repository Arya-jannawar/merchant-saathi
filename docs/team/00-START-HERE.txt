WHAT IS MERCHANT SAATHI?
An AI business partner for a small bakery owner. It shows ONE evidence-backed
opportunity (afternoon orders down 30%), proves the numbers behind it, drafts
the offer and customer message with AI, and turns the owner's approval into a
trackable SIMULATED campaign. The USP: "Proof, not a black box" - every number
links to its source, and unprofitable offers are visibly rejected.

GET RUNNING IN 10 MINUTES (short version - file 05 has details)
  1. Install Node.js 20+ (LTS), Git, and nothing else.
  2. git clone https://github.com/Arya-jannawar/merchant-saathi.git
  3. cd merchant-saathi && npm install
  4. copy .env.example .env.local        (defaults are safe; no API key needed)
  5. npm run db:seed
  6. npm run fixtures:verify             (must print: All fixture checks passed)
  7. npm run dev  ->  open http://localhost:3000/merchant
  8. Click "Load sample data" and click through the whole flow.

WORKING WITH THE TEAM
  - Clone the repo, branch per task:  git checkout -b t3-hindi-copy
  - Small commits, pull request into main, someone else reviews.
  - Never commit .env.local, data/*.sqlite, or any real customer data.
  - If you change money/consent/approval logic, add or update a test in tests/.
